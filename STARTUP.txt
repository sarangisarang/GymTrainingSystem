GymTrainingSystem — Startup Instructions
=========================================

Voraussetzungen
---------------
- Python 3.12+
- Node.js 18+
- pip, npm


Backend starten
---------------
cd backend

# Erste Einrichtung (einmalig)
pip install -r requirements.txt
cp .env.example .env
# .env oeffnen und GEMINI_API_KEY + JWT_SECRET_KEY eintragen

# Server starten (mit .env laden!)
set -a && source .env && set +a
uvicorn main:app --host 0.0.0.0 --port 8000

# Pruefung: http://localhost:8000/docs


Frontend starten
----------------
cd frontend
npm install
cp .env.local.example .env.local   # falls vorhanden, sonst:
# NEXT_PUBLIC_API_BASE=http://localhost:8000 in .env.local setzen

npm run dev      # Entwicklung: http://localhost:3000
npm run build    # Produktions-Build pruefen


Wichtige Hinweise
-----------------
1. GEMINI_API_KEY fehlt:
   Backend startet, aber /ai/coach gibt 503 zurueck.
   Warnung erscheint im Startup-Log.

2. JWT_SECRET_KEY fehlt:
   Backend startet mit unsicherem Fallback-Key.
   In Production MUSS JWT_SECRET_KEY gesetzt sein.

3. Timezone:
   APP_TIMEZONE in .env setzen (z.B. Europe/Berlin, Asia/Tbilisi).
   Ohne Einstellung wird die Systemzeit des Servers verwendet.
   Wichtig fuer korrekte Wochengrenzen in den Analytics.

4. SQLite (Standard):
   Datenbank wird automatisch als gym.db im backend/-Ordner erstellt.
   Kein Setup noetig.

5. Port-Konflikt:
   Falls Port 8000 belegt ist:
     lsof -i :8000
     kill <PID>
